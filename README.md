# VelEngine

A modern 3D game engine written in C++ and DirectX, built with an ECS architecture, PBR pipeline, and custom UI tools.

## 🎮 Features

- ✅ Entity-Component-System (ECS) architecture
- ✅ Scene serialization (XML-based)
- ✅ Physically Based Rendering (PBR)
- ✅ Image-Based Lighting (IBL)
- ✅ Basic post-processing (bloom, tone mapping)
- ✅ Custom UI framework
- ✅ C++ scripting system for gameplay logic
- ✅ Editor tools with hierarchy, inspector, and transform gizmos (WIP)

## 🔧 Technologies

- C++17
- DirectX 12
- HLSL (shader code)
- dotNet (editor interface)
- Assimp (model loading)
- tinyxml2 (serialization)

## 🛠️ In Progress
